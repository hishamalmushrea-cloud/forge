# ‏MagWind — آلتا مغناطيس حقيقيتان (بلا وقود ولا شمس)

## الحكم (نهائي): لا كهرباء مجانية من المغناطيس وحده — البراهين: ‏why_not_free.md
المغناطيس **محول** لا **مصدر**: توربين الرياح قلبه مغناطيس دائم يحول الريح،
وعجلة كوري محرك مغناطيسي يحول الحرارة. هذا أقصى ما تسمح به الفيزياء — ونبنيه كاملًا.

## كل مصادر «لا وقود ولا شمس» مرتبة بصدق
| المصدر | قدرة منزلية واقعية | الحكم |
|---|---|---|
| 🌀 توربين 1.4م (تل/سطح عالٍ) | ‏~1400Wh/يوم | ← نبنيه (يعمل ليلًا!) |
| 🌀 توربين 1.4م (مدينة تعز ‏3م/ث) | ‏~300Wh/يوم | مكمل ليلي متواضع |
| 🚲 دراجة + مولد هوفر بورد | ‏50–100W أثناء التبديل | ساعة = مروحة سهرة (أرقام فقط) |
| 🔥 عجلة كوري (حرارة + مغناطيس) | ‏~10mW كهرباء | عرض علمي ← نبنيه |
| ‏TEG (مبني — تبويب قديم) | واطات من نار الطبخ | موجود |
| بيزو/RF/جوي | ميكرو واط | حساسات فقط |
| مغناطيس وحده | **صفر** | مستحيل فيزيائيًا |

## ما يُبنى هنا
‏`wind.py` (نموذج التوربين + منحنى القدرة، سيناريو تعز/تل) + ‏`curie.py` (حدود عجلة كوري) +
‏`firmware/` (متحكم تفريغ ‏dump الزائد + فرامل — **إجباري لسلامة التوربين**) +
دليلا البناء + تبويب المحاكي ‏16 + حقن مباشر في بطارية ‏homebatt100 عبر دايود.
