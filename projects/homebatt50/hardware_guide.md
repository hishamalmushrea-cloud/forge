## ‏2) موازنة الخلايا (أهم خطوة — لا تتجاوزها!)
1. وصّل الخلايا الأربع **توازيًا** (+ مع +، − مع −).
2. اشحنها معًا بشاحن ‏3.65V ‏10A حتى يهبط التيار ‏< ‏1A (‏24–48h).
3. الآن كلها ‏3.65V متطابقة — فكك وركب **تواليًا**.

## ‏3) التجميع (رسم ‏battery_pack.svg)
1. رتب +−+− وضع الباسبار (عزم ‏8Nm + شحم نحاس).
2. ألواح ضغط جانبية + شريط (الخلايا تنتفخ قليلًا — طبيعي).
3. ‏BMS: وصّل ‏B- أولًا ثم ‏B1←B4 بالترتيب، ثم كابل التوازن، ثم ‏B+ أخيرًا.
4. ⚠ غطِّ كل طرف تعمل بجانبه — شرر ‏50Ah = حريق/عمى.

## ‏4) التشغيل (رسم ‏wiring.svg)
1. MPPT ← البطارية أولًا (ليتعرف ‏12V) ثم الألواح (القاطع مفتوح ← أغلقه).
2. اضبط: شحن ‏14.6V، تعويم ‏13.8V، فصل ‏10.5V (الـ‏BMS يقطع ‏10V احتياطًا).
3. الانفرتر آخر شيء + اختبر حملًا صغيرًا ← كبيرًا تدريجيًا.

## ‏5) الاستخدام اليومي
- النهار المشمس: كل شيء مسموح (‏TV + شحن هواتف).
- المساء: ‏LED + مروحة + هاتفان (≈ ‏200Wh) — ‏TV باعتدال ‏≤ ‏3h.
- أسبوع غائم: اقطع ‏TV أولًا، ثم قلل المروحة — ‏LED والهواتف خط أحمر أخير.
- التخزين الطويل (سفر): اتركها ‏~50% وافصل الأحمال.

## ‏6) الصيانة والتوسع
- سنويًا: شد العزم + نظف الأطراف + راجع سجل ‏BMS (بلوتوث).
- للتوسع: بطارية ثانية كاملة (‏4S+‏BMS خاص) توازي الأولى — **لا تخلط خلايا قديمة/جديدة!**
- بديل الرصاص (‏100Ah ‏~$130): نفس الرسوم، لكن استبدال كل سنة وعمر ‏TCO أسوأ ‏6×.
