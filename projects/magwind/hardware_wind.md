# بناء توربين الرياح ‏1.4م — قلبه مغناطيس هوفربورد ‏N42

## ‏1) المشتريات (≈ ‏$120–180)
| القطعة | ~السعر | ملاحظة |
|---|---|---|
| محرك هوفربورد ‏36V ‏350W مستعمل (عجلة واحدة) | $30–50 | مولد ‏PMA مثبت ‏~150W |
| ‏3 شفرات ‏PVC ‏110مم (ماسورة ‏2م) أو خشب | $10 | قالب + صنفرة + موازنة! |
| ماسورة برج ‏6م + أسلاك شد + قاعدة | $30 | فوق كل العوائق — الارتفاع = طاقة |
| مقوم ثلاثي ‏35A + دايود حجب | $10 | ‏AC ← ‏DC للبطارية |
| متحكم تفريغ (‏MOSFET + مقاومة ‏300W) + مفتاح فرامل | $25 | **إجباري — يمنع التدمير الذاتي** |
| أسلاك + ذيل توجيه + براغي | $15 | الذيل ‏0.3م² |

## ‏2) التجميع
1. ثبت الشفرات على محور المحرك (وصلة مخرطة/مثقاب دقيقة) — **وازنها حتى تتوقف بأي وضعية**.
2. الذيل خلف المحور + البرج عمودي تمامًا + أسلاك شد ‏3 اتجاهات.
3. الأسلاك الثلاثة ← المقوم ← متحكم التفريغ ← دايود ← بطارية ‏homebatt (‏+ مع +).
4. مفتاح الفرامل يقصر أطوار المولد عبر المقاومة — **جرّبه قبل أول عاصفة**.

## ‏3) التشغيل والسلامة
- ⚠ **لا تفصل التوربين عن حمله في الريح أبدًا** — افرمله أولًا (بلا حمل يتسارع حتى يتفكك!).
- أول اختبار: رياح خفيفة + راقب الجهد — يجب ‏18V+ عند ‏3م/ث.
- عاصفة ‏> ‏12م/ث: افرمله يدويًا أو أنزله — القدرة المقننة ‏300W فقط.
- الموقع يصنع ‏80% من الناتج: سطح عالٍ/تل + يونيو–سبتمبر = الذهب.

## ‏4) التكامل مع بطارية المنزل
يحقن التوربين في نفس البطارية عبر دايود (لا تعارض مع ‏MPPT الشمسي) —
الليل والغيم للريح، والظهيرة للشمس. معًا: منزل لا يعرف الانقطاع.
