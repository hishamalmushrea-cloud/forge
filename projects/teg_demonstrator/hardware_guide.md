## 2) المكدس الميكانيكي (بالترتيب)
```
مروحة 12V ← مشتت (بارد) ← معجون ← TEG#1 + TEG#2 (الوجه الفارغ = الساخن نحو الأسفل)
← معجون ← صفيحة Al (بداخلها السخانان + الفيوز الحراري + مزدوجة K) ← عازل ← قاعدة
```
- شد متجانس بـ 4 براغي + نوابض (ضغط متساوٍ ضروري وإلا تشقق السيراميك).
- نقطة التشغيل الاسمية: Thot ‏≈137°C (‏ΔT ‏≈85، ‏P≈‏1.14W)؛ ممنوع تجاوز Thot=‏140°C (‏ΔT=90 يعطي 144°C ← مرفوض).

## 3) التوصيل الكهربائي
```
12V PSU(+) ──[10A فيوز]──┬── مروحة 12V ── GND
                         └── MOSFET(D) ← سخانات(2 تسلسل/توازي حسب التيار) ← فيوز حراري ← 12V+
Arduino D9 → MOSFET(G)  |  GND مشترك
TEG+ ── INA219(VIN+) ── مفتاح ── حمل 12Ω ── TEG-   (حلقة القياس)
MAX6675 → D4/D5/D6  |  DS18B20 → D2  |  USB → تسجيل CSV
```
- تيار السخانات: ‏80W/12V ≈ ‏6.7A ضمن حد المزود مع هامش التشغيل المتقطع (PWM).
- ممنوع أي جهد شبكة في أي جزء من الجهاز (C1).

## 4) قائمة السلامة (إلزامية قبل التشغيل)
- [ ] فيوز 10A + فيوز حراري 150°C موجودان ومختبران (استمرارية).
- [ ] لا تماس بين أسلاك السخان والكتلة المعدنية (عزل سيراميكي).
- [ ] السطح الساخن 130°C يسبب حروقًا — عازل + لافتة تحذير + لا لمس أثناء التشغيل.
- [ ] تهوية للمكان (حرارة ~30W مستمرة).
- [ ] حد برمجي: إطفاء السخان فورًا عند Thot‏>145°C أو فشل الحساس (مطبق في الكود).

## 5) تسلسل التشغيل الأول
1. فحص بصري + استمرارية + غياب القصر. 2. تشغيل بدون حمل: Voc‏≈0.6–7V حسب ΔT.
3. رفع تدريجي لـ Thot حتى 130°C. 4. توصيل حمل 12Ω وقياس P‏≥1W لمدة 10 دقائق.
5. اختبار الثبات ساعة كاملة. التفاصيل في `test_plan.md`.
