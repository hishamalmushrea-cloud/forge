# التقرير النهائي: عقدة حساس بعقود دون شحن — من الصفر إلى خطة بناء واختبار كاملة

## PROJECT / OBJECTIVE
R1: ‏≥20 سنة دون شحن. الاختيار الاسمي: إرسال كل 30 دقيقة ← عمر محسوب **‏28.5 سنة**.

## RESEARCH
مصدر v0.2 ‏(Ni-63 ‏0.69g ← ‏100µW ‏BOL) + حصاد LTC3108 ‏(20mV، موثق سابقًا) + فيزياء المكثف الفائق.

## SELECTED APPROACH
بيتافولطي ← LTC3108 ‏(3.3V) ← مكثف 0.1F ← متحكم نوم 2µW ← رشقات LoRa ‏50mJ — مع مصدر بديل ‏30µA يتيح اختبار كل الإلكترونيات دون إشعاع.

## DESIGN
عازل لا نهائي الدورات (مكثف بدل بطارية كيميائية تموت قبل R1)، مفتاح حمل فيزيائي، برنامج واعٍ بالطاقة (لا إرسال تحت 2.2V).

## CALCULATIONS [CALCULATED]
العمر مقابل المعدل: ‏15د←0سنة، ‏20د←1، ‏25د←16، **‏30د←28.5**، ‏45د←53.5، ‏60د←69.5، ‏120د←101.5.
هامش العازل ‏6.9×، زمن الشحن ‏19.8 دقيقة (يحدد الحد الأدنى للمعدل — اتساق فيزيائي جميل).

## SIMULATION
أسبوع كامل بخطوة دقيقة: Vcap ‏≥2.43V دائمًا (‏`chart_week.svg`) — PASS بهامش مريح فوق حد 2.0V.

## TESTS
نموذج 5/5 [VERIFIED] (رتابة العمر، R1، العازل، زمن الشحن، صلاحية المخططات). فيزيائي T1–T5: ‏PENDING.

## CRITICAL REVIEW (نقاط قد تقتل المشروع — مسجلة بصدق)
1. تسريب المكثف حرج: 5µA ← العمر ‏9.5 سنة (يفشل R1). الحل: انتقاؤه ≤2µA أو تخفيض المعدل — الاختبار T4 يكشف الحقيقة.
2. ‏E_burst=‏50mJ وETA_HARV=‏50% افتراضان كبيران — T3/T2 يعايرانهما قبل أي ادعاء نهائي.
3. البرنامج غير مُنفذ على عتاد (pseudo-C) — يحتاج بورت لمتحكم محدد.
4. الجزء النووي: REQUIRES LICENSED FACILITY — العقدة الكاملة غير قابلة للبناء الفردي، والإلكترونيات وحدها قابلة.

## FINAL RESULT
حزمة كاملة: نموذج طاقي + BOM + دليل + برنامج + 5 اختبارات — أول تصميم في هذه السلسلة يصل لعقود دون شحن **فيزيائيًا** (بشرط المصدر المرخص).
