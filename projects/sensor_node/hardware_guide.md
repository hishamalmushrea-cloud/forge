# دليل البناء: عقدة الحساس البيتافولطية (الإلكترونيات كاملة + المصدر تحليلي)

## الخطوة 0 — حدود صادقة
- المصدر النووي (Ni-63): تصميم تحليلي فقط، تنفيذه الفيزيائي في منشأة مرخصة حصرًا.
- كل ما عدا ذلك (حصاد + عازل + متحكم + راديو + برنامج) قابل للبناء والاختبار الكامل هنا
  باستخدام **المصدر البديل**: مصدر تيار ~30µA يحاكي خرج البيتافولطي (‏100µW عند ~1V، مقاومة عالية).

## الخطوة 1 — BOM الإلكترونيات
| # | المكون | المواصفة | ملاحظة |
|---|--------|-----------|--------|
| 1 | لوحة حصاد LTC3108 + محول 1:100 | خرج 3.3V قابل للاختيار | يعمل من 20mV — موثق سابقًا |
| 2 | مكثف فائق 0.1F/5.5V **منخفض التسريب** (≤2µA) | عازل الطاقة | التسريب حرج: 5µA تُسقط العمر إلى 9.5 سنة (مثبت بالحساب) |
| 3 | متحكم نوم عميق (نوم ≤1µA، فئة MSP430/STM32L) | منطق القياس والإرسال | تحقق من ورقة البيانات قبل الشراء |
| 4 | وحدة راديو LoRa دون-غيغاهرتز | رشقة ~50mJ | قِس الطاقة الفعلية في T3 — الافتراض يُعاير |
| 5 | حساس حرارة رقمي (I2C) | القياس | استهلاك µA |
| 6 | مفتاح حمل (MOSFET) + مقسم قياس Vcap | فصل الحمل عند Vcap‏<2.0V | حماية العازل من التفريغ العميق |
| 7 | المصدر البديل: TL431 ‏(1.25V) + مقاومة 39kΩ + مليميتر | ~30µA معاير | يحل محل البيتافولطي في كل الاختبارات |
| 8 | صندوق + هوائي + بطارية CR2032 **للاختبار الأول فقط** | تُزال بعد T2 | لتمييز أعطال البرنامج عن أعطال الحصاد |

## الخطوة 2 — التجميع
```
[بديل 30µA (أو بيتافولطي مستقبلًا)] → [LTC3108 → 3.3V] → [مكثف 0.1F] → [مفتاح حمل] → [MCU+حساس+LoRa]
                                          ↑ قياس Vcap (ADC) → قرار الإرسال
```
1. ركّب الحصاد والمكثف أولًا، غذِّهما بالبديل، وتأكد من بلوغ 3.3V (زمن الشحن الأول ~ساعات — طبيعي!).
2. أضف المتحكم والراديو، وارفع البرنامج أدناه.

## الخطوة 3 — البرنامج (منطق واعٍ بالطاقة — pseudo-C)
```c
// كل استيقاظ (مؤقت 30 دقيقة):
read Vcap;
if (Vcap < 2.3) { sleep_again(); }          // طاقة غير كافية: تخطَّ الدورة (رُفعت من 2.2: الرشقة من 2.2 تهبط لـ1.96V)
read temperature;
power_radio(); send_packet(temp, Vcap); power_off_radio();
verify Vcap > 2.0 else extend_sleep();      // حماية تكيفية
deep_sleep(30 min);
```
- مفتاح الطاقة: الراديو والحساس يُفصلان فيزيائيًا بالمفتاح أثناء النوم (لا اعتماد على نومهما الداخلي وحده).
- أول إقلاع: لا إرسال حتى Vcap‏>3.0V (تجنب التذبذب على عتبة التشغيل).

## الخطوة 4 — الإقلاع الأول والمعايرة
1. عاير البديل: اضبط ~30µA بالمليميتر (T1). 2. تحقق من إقلاع LTC3108 وشحن المكثف (T2).
3. قِس طاقة الرشقة الفعلية (T3) — إن تجاوزت 50mJ أعد حساب المعدل من `calculations.py` قبل المتابعة.
4. شغّل 7 أيام وقارن منحنى Vcap بالمحاكاة (T4). 5. الشيخوخة المعجلة: خفّض البديل على منحنى v0.2 (T5).
