# بطارية المنزل ‏50 — ‏12.8V ‏50Ah شمسية تعيش ‏8+ سنوات

## القرار الكيميائي (لماذا ‏LiFePO4؟)
«تدوم كالنووي» = دورات × احتفاظ شحن: ‏LiFePO4 يعطي ‏~3000 دورة (مخفضة للحرارة)
وتفريغًا ذاتيًا ‏~3%/شهر مقابل ‏400 دورة و‏~20%/شهر للرصاص — و‏TCO أرخص ‏6×/‏10 سنوات.

## المنظومة
- بطارية: ‏4 خلايا ‏3.2V ‏50Ah توالي (‏640Wh، صالح ‏576Wh) + ‏BMS ‏4S ‏100A.
- شمسي: لوح ‏200W + ‏MPPT ‏20A (شحن كامل بيوم مشمس واحد من ‏20%).
- خرج: انفرتر ‏1kW جيبي + فرع ‏DC ‏12V مباشر (‏LED/مروحة أوفر بلا تحويل).
- حماية: فيوز ‏100A رئيسي + ‏25A شحن + ‏15A ألواح + ‏10A ‏DC + تأريض.

## يشغّل / لا يشغّل (بأمانة)
✅ إضاءة + مروحة ‏DC + هواتف + ‏TV ‏3h + راوتر (≈ ‏550Wh/يوم).
⚠️ ثلاجة ‏A++ ‏~800Wh/يوم: تحتاج بطارية ثانية (موثق التوسع ‏2P).
❌ مكيف/سخان/غسالة: مستحيل بهذا الحجم — أي من يعدك يكذب.

## الملفات
`sizing.py` (الأحمال ← التحجيم + ‏4 ‏SVG) + ‏`life_tco.py` (العمر والتكلفة) +
‏`firmware/` (مشرف ‏BMS مختبر) + دليل البناء + تبويب المحاكي ‏15.
