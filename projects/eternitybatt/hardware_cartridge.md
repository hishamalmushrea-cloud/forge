# دليل خرطوشة الماء المالح (‏v1 آمنة — ‏8.6Wh طوارئ)

## المبدأ
ألمنيوم + أكسجين الهواء + ماء مالح = كهرباء (‏0.9V/خلية). ‏8 خلايا ‏4S2P ← ‏0.86W
← رافع ‏5V ← ‏+47% هاتف في ‏~10 ساعات. بطيئة لكنها تعمل بلا شمس ولا كهرباء أصلًا.

## القطع (من السوق)
‏8 شرائح ألمنيوم ‏5×6cm (صفيح ‏1050) + لباد كربوني (فلتر أحواض!) ‏8 قطع +
‏8 فواصل بلاستيكية + علبة + ملح طعام + ماء + أسلاك + ‏MT3608.

## التركيب
1. شطيرة: ألمنيوم | ماء مالح | لباد (مكشوف للهواء) × ‏8.
2. ‏4 توالي × ‏2 توازي ← قس ‏~3.6V فارغة.
3. ← ‏MT3608 (اضبط ‏5.0V) ← ‏USB ← الهاتف.
4. اسكب الماء المالح وشاهد الشحن يبدأ (تبويب ‏14 يحاكيها).

## الصيانة والأمان
- يتآكل الألمنيوم (وقود!) ويجف الماء: بدّل الشريحة والماء كل تشغيلة.
- ☠️ مسار ‏NaOH (‏×3–5 قدرة) للخبراء فقط: نظارات + قفازات + تهوية — ‏v1 ماء مالح فقط.
- لا تشحن ليثيوم مباشرة من الخرطوشة دون الرافع المنظم.
