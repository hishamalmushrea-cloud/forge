# همس بعيد — رسائل ‏10km+ مشفرة بلا إنترنت

## البنية
هاتف (واجهة + تشفير همس) ←بلوتوث→ عقدة جيبية (‏ESP32 + ‏SX1262 ‏~$15) ←‏LoRa مشفر→
عقد جيبية أخرى (شبكة فيضية ‏TTL=6 + تخزين-وتمرير) ←→ هاتف المستلم.

## البروتوكول
- إطار ‏LoRa: ‏ capsule همس (‏171B ≈ رسالة) داخل إطار ‏mesh ‏≤200B (‏src/dst/msg/TTL/frag/CRC).
- القفز: كل العقد نفس جدول الفوضى (بذرة الشبكة) + طور الـslot عبر منارات ch0 كل ‏60s؛
  البيانات تقفز (مضاد للتشويش)، والانضمام عبر ch0.
- ‏SF9/125kHz افتراضيًا (~‏0.95s/رسالة)، ‏SF12 احتياطي للمسافات القصوى؛ دورة عمل ‏1% ≈ ‏37 رسالة/ساعة.
- الأمان: التشفير طرف-لطرف (العقد الممررة ترى الترويسات فقط) + بصمات همس.

## ما بعد ‏Meshtastic (بأمانة: ‏Meshtastic موجود وناضج)
| الميزة | Meshtastic | همس بعيد |
|---|---|---|
| القناة | ثابتة (تُشوَّش بسهولة) | قفز فوضوي (‏47.9% تحت وابل ‏50%) |
| التشفير | ‏PSK مشترك | ‏ECDH لكل جهة + بصمات |
| التمرير | فيضي | فيضي + تخزين-وتمرير للمنقطعين |
| الواجهة | إنجليزية | عربية أولًا، تعمل أوفلاين |

## الملفات
`link_budget.py` (إثبات ‏10km) + `mesh_sim.py` (الشبكة + ‏SVG) + ‏`firmware/` (عقدة حقيقية + اختبار ‏5 عقد)
+ تبويب المحاكي ‏12 (التطبيق الحي).
