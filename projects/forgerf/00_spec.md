# ‏ForgeRF-1 + محطة الكشاف — ‏SDR يتفوق على ‏HackRF Pro

## الخصم (موثق ‏2026)
‏HackRF Pro ‏$400: ‏100kHz–6GHz، نصف-مزدوج، ‏8-بت، ‏20Msps، ‏USB-C، ‏TCXO.
نقاط ضعفه: ‏8-بت (مدى ديناميكي ‏~50dB) + نصف-مزدوج + حماية إرسال صفرية.

## ‏ForgeRF-1 (التصميم — ‏DESIGNED)
‏AD9361 (‏12-بت، ‏70M–6G، ‏56MHz) + ‏Zynq + ‏preselector + ‏TCXO + ‏USB-C +
‏bias-tee + تدريع + **ماسح مستقل ‏RP2040** + **جدار ناري ‏TX** — يتفوق بالنظافة
(‏+24dB) والازدواج الكامل والسلامة. التكلفة DIY ‏~$500 (‏AD9361 وحده ‏~$180!)
مقابل ‏$400 جاهز — القيمة هنا التصميم والبرمجيات والأدوات، لا التوفير.

## محطة الكشاف (البناء الحقيقي — ‏BUILDABLE ‏~$120)
‏RTL-SDR V4 + ‏LNA + فلتر ‏FM + هوائيات (تلسكوبي + دايبول + ‏QFH للأقمار) + حاسوب:
تستقبل ‏500kHz–1.75GHz (‏FM، طيران، ‏NOAA، ‏ISS، ‏LoRa) — استقبال فقط = قانوني دائمًا.

## الإبداعات (من عندي)
1. **جدار ناري الإرسال**: الفيرموير يرفض الإرسال خارج النطاقات المسموحة/القدرات
   (‏ISM + هواة برخصة)، ويحظر الطوارئ والطيران، ويراقب الموجة المستمرة.
2. **ماسح مستقل**: وضع ‏RP2040 يمسح ويسجل على ‏SD بلا حاسوب.
3. **ربط مشاريعنا**: إعدادات ‏433/868 ‏LoRa جاهزة + مسجل نطاق ‏farwhisper.

## الملفات
‏`linkbudget.py` (الحسابات + إثبات ‏12-بت) + ‏`firmware/` (الجدار الناري) +
دليلا البناء/التصميم + تبويب ‏18 (راسم طيف + تجربة الجدار الناري).
