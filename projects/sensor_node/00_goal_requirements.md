# مشروع: عقدة حساس ببطارية نووية + عازل — عقود دون شحن

## GOAL
جهاز ميكروواط (حساس حرارة + إرسال لاسلكي دوري) يعمل عقودًا دون أي شحن خارجي،
بمصدر Ni-63 بيتافولطي ‏100µW ‏(v0.2) + مكثف فائق عازل + حصاد LTC3108 + متحكم نوم عميق.

## REQUIREMENTS
| # | المتطلب | القيمة | الحالة |
|---|---------|--------|--------|
| R1 | عمر تشغيلي | ≥ 20 سنة دون شحن/صيانة | ASSUMED (تفسير "عقود") |
| R2 | الوظيفة | قياس حرارة + إرسال لاسلكي دوري | ASSUMED |
| R3 | المصدر النووي | تحليلي فقط — أي تنفيذ فيزيائي بمنشأة مرخصة | CONSTRAINT |
| R4 | قابلية الاختبار هنا | المصدر البديل (µA مضبوط) يختبر كل الإلكترونيات دون إشعاع | CONSTRAINT تصميمي |
| R5 | العازل | دورات لا نهائية (مكثف فائق، لا بطارية كيميائية تموت قبل 20 سنة) | DECISION مبرر |

## ARCHITECTURE
```
[Ni-63 ‏100µW ‏(v0.2) | بديل الاختبار: مصدر 30µA] → [حصاد LTC3108 ← 3.3V] → [مكثف 0.1F] → [مفتاح حمل]
 → [MCU نوم 2µW ← يستيقظ: يقيس ← يرسل LoRa ‏(~50mJ) ← ينام]   + [حماية: لا إرسال إذا Vcap منخفض]
```

## KEY DESIGN DECISIONS (مبررة)
- D1: مكثف فائق لا بطارية قابلة للشحن — البطارية الكيميائية تموت خلال ‏5–10 سنوات وتكسر R1.
- D2: ‏LTC3108 — يعمل من 20mV، مصمم أصلًا لحصاد TEG/الميكروواط (موثق سابقًا).
- D3: طاقة الرشقة ‏50mJ ‏(ASSUMED بهامش) — تُقاس وتُعاير في T3 قبل اعتماد معدل الإرسال.
- D4: كفاءة الحصاد 50% ‏(ASSUMED محافظة) + تسريب المكثف 2µA ‏(ASSUMED — مع تحليل حساسية).
