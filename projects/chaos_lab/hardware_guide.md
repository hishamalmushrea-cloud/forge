# دليل البناء: دائرة Chua الفوضوية (القيم موثقة من مصدرين)

## الخطوة 0 — القيم الموثقة (Kennedy، مصدران متطابقان)
L=‏18mH ‏(Bourns RL181S-183J-RC أو مكافئ)، ‏C1=‏10nF، ‏C2=‏100nF، ‏R= متغير ‏5kΩ (يتحكم بالنظام)،
ثنائي Chua: مضخمان (TL072) + ‏R1=R2=‏220Ω، ‏R3=‏2.2kΩ، ‏R4=R5=‏22kΩ، ‏R6=‏3.3kΩ. تغذية ±9V (بطاريتان).

## الخطوة 1 — BOM
| # | المكون | ملاحظة |
|---|--------|--------|
| 1 | TL072 ×2 + لوح تجارب + مقاومات القيم أعلاه + مكثفان | قلب الدائرة |
| 2 | ملف 18mH + مقاومة متغيرة 5kΩ دقيقة | الضبط الحرج — متعدد الدورات أفضل |
| 3 | بطاريتا 9V + مشابك | ±9V (الأرضي = الوسط) |
| 4 | Arduino + مقاومتا مقسم لكل قناة (10k/10k) | راسم X-Y بطيء (‏C1→A0، ‏C2→A1) |
| 5 | مليميتر | فحص التغذية والاستمرارية |

## الخطوة 2 — بناء ثنائي Chua (T0: طابق مع Kennedy Fig.1 قبل التغذية!)
1. ابنِ المرحلتين حسب مرجع Kennedy (الرابط في التقرير) — **لا تعتمد على ذاكرتي للتوصيل الدقيق**.
2. اختبر منحنى V-I: مثلث بطيء من Arduino ‏(PWM+مرشح) على الدخل ← يجب رؤية 3 ميول (سالب-موجب-سالب) — ‏T1.

## الخطوة 3 — الدائرة الكاملة وجولة التشعب (لحظة الدهشة)
1. وصّل L/C1/C2/R بالقيم أعلاه. ابدأ R=‏5kΩ (أقصى) ثم اخفض ببطء شديد.
2. سجل كل نظام: سكون ← تذبذب ← تضاعف الدور ← لولب مفرد ← **لولب مزدوج** (الفوضى!) — ‏T2–T4.
3. سجل CSV عبر Arduino وابعثه لي — سأرسم لك الجاذب الغريب من بياناتك.

## الخطوة 4 — السلامة والحدود
- ±9V آمنة اللمس. احذر قصر البطاريات فقط. تسامح المكونات يزيح الأنظمة — المقاومة المتغيرة تعوض (سجل قيم R لكل نظام!).
- راسم Arduino بطيء (~kHz) — يكفي لرؤية اللولب (‏~kHz) لا التفاصيل الدقيقة.
