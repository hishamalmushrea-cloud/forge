# بناء تطبيق همس الشريحة (أندرويد)

1. مشروع جديد (Kotlin, minSdk 26) + انسخ `*.kt` + ادمج `manifest_snippet.xml`.
2. التشفير: بوابة WebView لـ`whisper_core.js` (الأسرع والأدق — نفس الكود المختبر)،
   أو نقل ECDH/AES إلى Tink لاحقًا.
3. `WhisperSmsReceiver`: جمّع المقاطع حسب ‏msgid ← ‏`smsDecode` ← ‏`open` ← اعرض.
4. الرنّات: سجّل `RingListener` (خدمة أمامية) + جهات همس (أرقام + بصمات).
5. **سياسة Play**: صلاحيات ‏SMS/سجل المكالمات مقيدة — التوزيع عبر ‏F-Droid/تحميل جانبي
   (مثل ‏Silence الميت — نحن الوريث الشرعي بمصدر مفتوح).

## خطة ميدانية مختصرة
- ‏T0: شريحتان، رسالة مشفرة ← ‏2 مقطع ← تُفك ✓ + المزيفة تُرفض.
- ‏T1: رنّة/رنّتان/‏3 ← المعاني الثلاثة ✓ + رقم غريب يُتجاهل.
- ‏T2: وضع الطيران + ‏SIM فقط (بلا إنترنت) ← كل شيء يعمل.
