# مشروع: مختبر الفوضى — عشوائية وتشفير من الحتمية + دائرة Chua

## GOAL
نظام فوضوي كامل: (1) مولد بتات عشوائية من نظام Lorenz يُنفذ ويُختبر إحصائيًا هنا،
(2) شفرة انسيابية XOR للعرض، (3) دليل بناء دائرة Chua (فوضى تناظرية حقيقية بمكونات رخيصة).

## REQUIREMENTS
| # | المتطلب | القيمة | الحالة |
|---|---------|--------|--------|
| R1 | عشوائية إحصائية | monobit + runs + إنتروبيا ضمن الحدود | TESTED هنا |
| R2 | حتمية | نفس البذرة ← نفس الدفق (إعادة الإنتاج) | TESTED |
| R3 | حساسية البذرة | قلب بت واحد ← ~50% اختلاف بعد الإحماء | TESTED |
| R4 | دائرة Chua | قيم موثقة + راسم Arduino بطيء X-Y | GUIDED (بناء بيدك) |
| R5 | حدود أمنية | تعليمي فقط — ليس بديل AES/ChaCha20 | CONSTRAINT (موثق) |

## ARCHITECTURE
```
بذرة 128بت → (x0,y0,z0) → Lorenz RK4 → إحماء → عينات كل 25 خطوة → إشارة x
→ Von Neumann (إزالة انحياز) → بتات ← اختبارات إحصائية ← تشفير XOR (عرض)
عتاد: Chua (مضخمان + R/C/L) ← راسم Arduino ← مخطط X-Y (لولب مزدوج حي)
```

## HONEST FLAGS
- F1: دقة float المنتهية تعني دورات متكررة نهائيًا — للعرض لا للإنتاج الأمني.
- F2: Lorenz البرمجي حتمي نظريًا — "العشوائية" هنا لا-قابلية-تنبؤ عملية فقط.
