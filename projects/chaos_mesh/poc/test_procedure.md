# إجراء إثبات المفهوم اللاسلكي — من المحاكاة إلى القياس الحقيقي

## المشتريات (~$120 للمسار الكامل، ~$65 للأساسي)
- أساسي: ‏2× (ESP32 + ‏SX1262 433MHz) + أسلاك + موهنات ‏2×20dB + وصلة T (SMA).
- موسع: ‏RTL-SDR (استقبال واسع) + ‏HackRF One (بث/تشويش) أو أي TX قادر.

## المرحلة 0 — بدون عتاد (تُنفذ هنا، كلها خضراء)
1. `python3 poc/linksim.py` ← التوقعات + فرضيات العلم (asserts).
2. `gcc ... test_emulator` ← منطق العقدة/البوابة end-to-end (تشويش/انقطاع/تزوير).
3. `python3 poc/sdr/modem_check.py` ← المودم المرجعي + صيغة الحزمة.
4. `python3 poc/sdr/measure.py --selftest` ← كود التحليل.
5. `python3 poc/sync_check.py` ← محرك ESP32 مطابق للموثق بتًا-بتًا.

## المرحلة 1 — ESP32 سلكيًا (رابط الفوضى الحقيقي الأول)
1. انسخ `firmware_esp32/{common,radio_hal.h,hal_sx1262_radiolib.cpp,poc_node.*}` + ‏ino إلى Arduino IDE + ‏RadioLib.
2. وصّل العقدة↔البوابة عبر T + موهنات (لا هوائيات!) + شغّل — يجب: ‏CAP 100%.
3. مشوش مختبري = عقدة ESP32 ثالثة تبث ضجيج FSK على ch0–3 (نفس الكابل) — يجب: ‏PDR ≈ ‏50%.
4. اجمع Serial البوابة ← `measure.py captures.csv` ← أول صف **مقاس**.

## المرحلة 2 — هوائي قصير المدى (بعد نجاح السلكي فقط)
- قدرة ≤10mW، مسافة 3–10م، داخل مبنى. كرر المصفوفة: نظيف/وابل ‏1-2-4-6.

## المرحلة 3 — مصفوفة SDR الكاملة (4 مخططات)
- ‏TX: `tx.py --scheme {fixed,lfsr,hash,chaos}` × التشويش {لا يوجد، وابل، متتبع}.
- ‏RX: `rx.py --scheme ...` (بوابة ماسحة عريضة) ← ‏captures.csv.
- التشويش المضبوط: `jammer.py --mode barrage --channels 0,1,2,3 --gain G`؛
  عاير G سلكيًا أولًا: أقل كسب يُسقط co-channel إلى ‏PDR≈0 مع بقاء المجاور سليمًا.
- المتتبع الحي: سجّل captures ثم `jammer.py --mode follower-analyze` ← دقة التنبؤ المقاسة.
- املأ `results_table.md` (مقاس) وقارن مع `predicted.json`.

## السلامة والقانون
- التشويش محظور بثه خارج موقع الاختبار — ابدأ سلكيًا دائمًا، وهوائيًا بقدرة دنيا ومدة قصيرة.
- تحقق من لوائح ‏ISM المحلية (433.05–434.79) والتزم حدود القدرة ودورة العمل.

## معيار النجاح
صف «مقاس» يطابق «متوقع» ضمن ±10 نقاط مئوية + المتتبع يُسقط ‏LFSR ويعجز عن الفوضى/HASH.
عندها فقط يُكتب الحكم النهائي في `results_table.md`.
