# بطارية الخلود — أقرب شيء حقيقي لـ«نووية»

## الحكم النووي (نهائي وموثق)
- ‏Betavolt Ni-63: ‏100µW ← الهاتف يحتاج ‏250mW معدل (‏2500× أقوى) — مستحيل فيزيائيًا.
- ‏RTG بلوتونيوم: ممكن فيزيائيًا (~‏8g ‏Pu-238) لكن غير قانوني/مجنون التكلفة — مرفوض أخلاقيًا وهندسيًا.
- **لن يُصمم أي شيء إشعاعي في هذا المشروع أبدًا.**

## النظام (‏3 طبقات)
1. **وضع الخلود** (الهاتف): جدولة الراديو + تجميع البيانات + سقف الشاشة + ليالي الطيران —
   ‏2.5 ← ‏7.5+ أيام بنفس البطارية ‏18.5Wh.
2. **المحطة الجيبية** (‏40Wh + شمسي ‏5W + ‏TEG): ‏15Wh/يوم ← استدامة لا نهائية تحت الشمس.
3. **خرطوشة الماء المالح** (معدن-هواء ‏4S2P): ‏0.86W × ‏10h ≈ ‏8.6Wh ← ‏46% شحنة طوارئ بلا كهرباء أصلًا.

## الملفات
`eternity.py` (النموذج + المقارن النووي + الخرطوشة) + ‏`firmware/` (شاحن ‏MPPT حقيقي مختبر)
+ دليلا العتاد (محطة + خرطوشة آمنة بماء مالح فقط ‏v1) + تبويب المحاكي ‏14.
