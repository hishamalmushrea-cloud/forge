# التقرير النهائي: محلل الماء القلوي — من الصفر إلى جهاز قابل للبناء والاختبار

## PROJECT / OBJECTIVE
استخلاص H2 + ‏O2 من الماء: R1 ≥ ‏1.5 L/h هيدروجين، فصل كامل للغازين، 12V فقط، قياس مباشر.

## RESEARCH (موثق)
- جهد الخلية القلوية 1.8–2.4V، استهلاك نوعي 4.5–7.0 kWh/Nm³، إلكتروليت KOH 25–30%، ستانلس مستقر للمصعد.
- نموذجنا عند 2.0V يعطي 4.78 kWh/Nm³ ← داخل المدى المرجعي (تحقق متقاطع ناجح).

## SELECTED APPROACH
خلية هوفمان DIY بغرفتين (لا خليط متفجر)، أقطاب 316SS ‏~100cm²، ‏KOH ‏~20% (تركيز محافظ)، تيار ثابت 4A بوحدة باك.

## DESIGN
حوض + قطبان + أسطوانتا جمع مدرجتان + تهوية خارجية + قياس INA219/Arduino مع تنبؤ فاراداي لحظي وفصل حماية (5A/ساعتين).

## CALCULATIONS [CALCULATED]
4A ← **H2 ‏1.82 L/h** + ‏O2 ‏0.91 L/h بقدرة 8W (‏4.38 Wh/L، كفاءة LHV ‏63.6%، كفاءة جهد 61.5%).

## SIMULATION / TESTS
منحنى التيار 1–10A في `chart.svg`. النموذج 5/5 [VERIFIED] (فحص يدوي + نطاق مرجعي + اتساق كيميائي). فيزيائي T1–T5: PENDING.

## CRITICAL REVIEW
1. كفاءة فاراداي 100% مثالية — الفقاعات العالقة والحرارة تخفضها؛ T2 سيكشف الحقيقة.
2. التآكل البطيء للستانلس يلوّن المحلول مع الزمن ← صيانة وتنظيف دوري.
3. أسطوانات بلاستيكية مدرجة يدويًا أقل دقة من الزجاج ← خطأ قياس مُدخل في حد ±15%.
4. أي إغلاق لمخارج الغاز = قنبلة ← التحذير مكرر في الدليل والكود (قطع زمني احتياطي).

## FINAL RESULT
حزمة بناء كاملة خطوة بخطوة: متطلبات + نموذج + BOM + دليل تجميع + كود + خطة قبول.
