# همس الشريحة — الناقلان ‏4 و‏5 لكبسولة همس

## الناقل ‏4: ‏SMS مشفر (‏E2E)
كبسولة همس ← مقاطع ‏data-SMS ثنائية (‏140B/مقطع، منفذ تطبيق ‏8091):
ترويسة ‏5B (‏ver/msgid/total/idx/crc8) + ‏135B حمولة ← ‏171B = مقطعان.
المشغّل يرى شفرة فقط. التكلفة = مقطعان/رسالة (ليست مجانية — بأجر المشغل).
‏Silence (الوحيد عالميًا) ميت منذ ‏2019 — نحيي الفئة بتشفير أحدث وواجهة عربية.

## الناقل ‏5: رنّات مجانية (‏1-بت)
أنماط متفق عليها: رنّة = «تمام ✓»، رنّتان = «اتصل بي ضروري»، ‏3 = «تعال/خطر».
مجانية حقًا (لا يُردّ على المكالمة)، تحتاج ظهور رقم المتصل + صلاحية حالة الهاتف.
مضحكة الحدود لكنها حقيقية — إشارة طوارئ بلا رصيد.

## الحدود المعلنة
- ‏SMS: مدفوع + ‏160/70 حرفًا للنص العادي؛ الثنائي يحتاج التطبيق عند الطرفين.
- الرنّات: ‏~2 بت/دقيقة، وقد يحجبها المشغل أو يؤخرها؛ ليست بديلًا للرسائل.
- أندرويد: ‏SEND/RECEIVE_SMS + ‏READ_PHONE_STATE (سياسة ‏Play صارمة ← تحميل جانبي موصى).

## الملفات
`sms_codec.py` (تقطيع + ذهبي ‏JS) + ‏`ring_code.py` (بروتوكول الرنّات) + ‏`android/` (هيكل ‏Kotlin غير مترجم هنا)
+ تبويب المحاكي ‏13 (‏SMS حقيقي التشفير + رنّات + فحص ذهبي).
