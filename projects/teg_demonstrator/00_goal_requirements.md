# مشروع: مولد حراري-كهربائي (TEG) — نظير RTG الآمن الكامل

## GOAL
بناء مولد حراري-كهربائي مكتمل من الصفر حتى جهاز مُختبَر، يطابق معمارية البطارية النووية الحرارية (RTG)
مع استبدال مصدر الحرارة المشع بسخان كهربائي آمن 12V. الفيزياء المستهدفة: تحويل Seebeck الحراري-الكهربائي.

## REQUIREMENTS
| # | المتطلب | القيمة | الحالة |
|---|---------|--------|--------|
| R1 | خرج كهربائي مُقاس عند الحمل المطابق | ≥ 1 W | ASSUMED (هدف تعليمي مجدٍ) |
| R2 | فرق الحرارة التشغيلي | ΔT ≈ 60–100 K | ASSUMED |
| R3 | السلامة الكهربائية | جهد منخفض فقط (≤12V DC)، ممنوع جهد الشبكة | CONSTRAINT |
| R4 | السلامة الحرارية | سطح ساخن ≤ 150°C + تحذير حرق + عزل | CONSTRAINT |
| R5 | قابلية القياس | جهد/تيار/حرارتين مسجلة | ASSUMED |
| R6 | التكلفة | مكونات تجارية رخيصة متوفرة أونلاين | ASSUMED |

## ARCHITECTURE (مطابق RTG)
```
[سخان 12V: نظير النظير المشع] → [صفيحة ساخنة Al] → [وحدات TEG ×N] → [مشتت + مروحة: نظير مشعاع RTG]
                                                                     ↓ كهرباء (mV–V)
                                                        [إدارة طاقة: LTC3108 أو Boost] → [حمل/تخزين] → [قياس وتسجيل]
```

## CONSTRAINTS / ASSUMPTIONS
- C1: كل الدوائر ≤12V DC. C2: لا مواد مشعة إطلاقًا — هذا الجهاز تعليمي صرف.
- A1: مواصفات وحدة TEG من ورقة البائع (SOURCE VERIFIED بعد البحث).
- A2: مقاومة حرارية للمشتت مع مروحة ≈ 0.5–1.0 K/W (ESTIMATED، تُضبط بالتجربة).
- A3: حمل مطابق R_load = R_internal عند حساب Pmax.
